# Phase 7a 手動測試：廣告、音效、清理、版本

Debug 版只會載入 Google 官方測試廣告 ID。Release 版才用真實 ID。

## A. 模擬器（F33D7A61）用測試廣告

Debug 啟動時不要帶 `-noAds`。要用測試廣告又要 QA 起始狀態時，帶 `-seed 20261116 -testAds`（存檔仍是 `save-qa.json`，不動真實存檔）。

| # | 步驟 | 預期 |
|---|---|---|
| A1 | `-seed 20261116 -testAds -stage 1 -picks 1 -boomPair -shield 0`，點一張牌 | 出現手數用完面板。廣告載入前按鈕灰色，寫「廣告暫時無法載入」；載入好之後變成「看廣告，多 2 手」 |
| A2 | 按「看廣告，多 2 手」，看到結尾「報酬を獲得しました」再按右上 X | 回到遊戲，剩 2 手，畫面顯示「多了 2 手」。再次失敗後面板不再給看廣告的機會（每局一次） |
| A3 | 同 A1，廣告播到一半就關掉（獎勵前） | 回到手數用完面板，手數不變，按鈕可再按或「結束這局」 |
| A4 | 飛航模式後啟動，走到手數用完面板 | 載入還沒失敗時按鈕寫「廣告載入中…」，第一次載入失敗後改成「廣告暫時無法載入」，都是灰色，「結束這局」正常。關掉飛航模式等一下，按鈕自動恢復 |
| A5 | `-testAds -adCounter 2 -stage 1 -picks 1 -boomPair -shield 0`，失敗後按「結束這局」 | 先出現插頁測試廣告，關掉後才出現結算面板 |
| A6 | 再連打兩局（不帶 adCounter）到結算 | 前兩局沒有插頁，第三局才有 |
| A7 | 今日挑戰第一次挑戰失敗 | 即使輪到插頁也不出現；第二次挑戰結算才可能出現 |
| A8 | 插頁還沒載入時結算 | 結算面板立刻出現，沒有等待、沒有錯誤 |
| A9 | 商店面板、結算面板底部 | 橫幅釘在畫面底部（面板外），上方有細線和「廣告」小字，離最近的按鈕至少 24 pt；iPhone SE 上整條廣告完整可見；失敗時整條收起 |
| A10 | 主畫面、手數用完面板、難度面板、規則面板、我的紀錄 | 都沒有橫幅 |
| A11 | 廣告播放中聽遊戲音效 | 遊戲音效靜音，廣告結束後恢復 |
| A12 | 啟動、切到背景再回來 | 不再跳出開啟 App 廣告 |

自動化版本：`TEST_RUNNER_SHOTS_DIR=<資料夾> xcodebuild test ... -only-testing:BoomOrBonusUITests/AdsUITests`（需要網路與測試廣告填充，不在預設套件內）。獎勵廣告用 `app.buttons["Close"]` 關閉，等 `報酬を獲得しました` 出現後再按，之後驗證「剩 2 手」。

## A2. 同意（UMP，EEA / 英國 / 瑞士）

Google 要求這些地區使用認證的同意管理平台。程式用 UMP：啟動後先向 UMP 要同意資訊，需要時顯示表單，`canRequestAds` 為 true 才啟動廣告 SDK 並載入廣告（上一次已同意時，啟動就直接開始）。同意流程失敗或沒有設定訊息時，遊戲照常進行，只是不載入廣告。

**使用者要做：** 在 AdMob 後台為這個 App 設定並發布「GDPR 訊息」（隱私權與訊息 > 歐洲法規）。沒有發布訊息時，任何地區都不會出現表單（模擬器用 `-umpEEA` 也一樣，這是目前在模擬器上看不到表單的原因）。

| # | 步驟 | 預期 |
|---|---|---|
| U1 | `-seed 20261116 -umpEEA`（Debug，模擬器視為 EEA，並清掉已存的同意） | 後台訊息已發布時，啟動後出現同意表單；選完後才開始載入廣告。遊戲畫面一直可操作，不會被等待卡住 |
| U2 | 同意後打開 ?（規則）面板 | 地區需要時，按鈕列多一個「隱私設定」，按下去可重新選擇；不需要的地區不顯示 |
| U3 | 拒絕或關閉表單 | 遊戲照常，依 UMP 結果決定是否載入廣告 |
| U4 | 飛航模式啟動 | 沒有表單、沒有廣告，遊戲正常；恢復網路後下次啟動再試 |

## B. 音效（模擬器可先聽，真機再確認）

| 事件 | 預期 |
|---|---|
| 點牌 | 每格一聲短促滴答，音高逐格升高 |
| 安全 | 清脆和弦，連中越多音越高（到第 9 級封頂） |
| 爆炸 | 低沉爆裂聲 |
| 保命符、拆彈 | 兩音上揚 |
| 達標 | 三音上行（安全音之後） |
| 過關 | 五音上行 |
| 手數用完 | 三音下行 |
| 商店購買 | 金幣聲；換一批、用道具：短二音 |
| 新紀錄膠囊出現 | 金幣聲 |
| 新的一局 | start.mp3 |
| 其他按鈕 | Click.mp3 |
| 規則面板「關閉音效」 | 全部靜音，包含合成音 |

流暢度：連點 5 手，每手約 1 秒，沒有卡頓（UI 測試 `testPickFlowStaysSmoothWithSoundOn` 量過）。

## C. 真機專用檢查表

- [ ] 真實廣告填充：獎勵廣告、橫幅可載入並播放（Release 或 TestFlight，不要用自己的帳號點廣告）。
- [ ] 插頁：Release 在使用者建好插頁廣告單元、換掉 `INTERSTITIAL_UNIT_ID_TODO` 之前不會出現（預期行為）。換好之後每 3 局出現一次。
- [ ] 實體靜音開關打開：沒有任何遊戲音效（`.ambient`）。
- [ ] 背景有音樂 App 在播放：開遊戲後音樂不中斷，遊戲音效疊在上面。
- [ ] 遊戲中來電或 Siri：結束後音效恢復，不當機。就算系統沒有送「結束」通知，下一個音效也會自動重啟引擎（每 0.5 秒最多試一次），回到前景時也會重啟。
- [ ] 連上 AirPods，遊戲中拔掉再接上：音效不當機，之後仍有聲音。
- [ ] 廣告播放中音樂 App 的行為正常，廣告結束後遊戲音效恢復。
- [ ] 版本顯示 2.0（build 2）。
