# Phase 5 手動測試步驟：新手導覽、規則面板、就地說明

Debug build，模擬器或實機。啟動參數寫法同 Phase 3／4：Xcode scheme 的 Arguments，或
`xcrun simctl launch booted CHIA.BoomOrBonus -seed 4242 -noAds -today 20261116 ...`。

**存檔隔離**：帶 `-seed` 的啟動使用 `save-qa.json`（每次啟動清空），不會動到真正的 `save-v6.json`。

## 新增的啟動參數

| 參數 | 作用 |
|---|---|
| `-onboarding` | 搭配 `-seed`：強制出現第一次開啟的新手導覽。沒有這個參數時，`-seed` 啟動一律視為已看過導覽（不擋 UI 測試）。完成或跳過後寫進 `save-qa.json`，之後用 `-qaSave -noAds` 重開不會再出現。 |

`?` 直接打開規則面板（02 §2.1）。面板底部固定的按鈕：`關閉音效`、`再看導覽`、`選擇難度`、`放棄（算一次）`／`放棄重來`、`回到遊戲`（Phase 6 會在同一排加 `我的紀錄`）。沒有另外的選單。

## 一、新手導覽（六步）

| # | 步驟 | 預期 |
|---|---|---|
| 1 | `-seed 4242 -noAds -today 20261116 -onboarding` 開啟 | 畫面變暗，分數區（大分數、目標說明、進度條、進度條標籤）被挖空並有金色外框；外框貼著分數區，不是整個畫面。分數區在畫面上半，所以說明卡在外框**下方**。卡片寫 `新手導覽 1 / 6`、`目標分數`、說明、`跳過`、`下一步`。 |
| 2 | 點暗處（包含挖空的地方、牌上） | 沒有任何反應：沒有選牌，導覽停在原步驟。 |
| 3 | 點 `下一步` | 外框滑到兩張牌（0.32 秒）。目標在下半部，說明卡在外框**上方**。標題 `二選一，看危險度`。 |
| 4 | 繼續 `下一步` 到第 3、4、5 步 | 依序圈出：手數與連中那一列、四格道具列、過關按鈕。標題 `手數與連中`、`保命符與道具`、`過關拿金幣`。每一步外框都完整框住目標，說明卡不蓋住外框、不超出螢幕。 |
| 5 | 第 6 步 | 回到分數區，標題 `要不要拚超標？`。沒有 `跳過`，按鈕寫 `開始玩`。 |
| 6 | 點 `開始玩` | 導覽消失，可以正常選牌。 |
| 7 | 殺掉 App，用 `-qaSave -noAds -today 20261116` 重開 | 不再出現導覽。 |
| 8 | 另開一次 `-onboarding`，第 1 步點 `跳過` | 導覽消失。重開（`-qaSave`）不再出現。 |
| 9 | 導覽進行中，看頂端的模式切換、右上角 `?`、`★` | 全被遮罩蓋住，點了沒反應。 |
| 10 | 不帶 `-onboarding`（一般 `-seed` 啟動） | 不出現導覽。 |
| 11 | 真正第一次安裝（刪除 App 後重裝，Release 或不帶 `-seed` 的 Debug） | 導覽自動出現；做完或跳過後，再開不會出現。 |

### 各螢幕尺寸

iPhone SE（第 3 代）、iPhone 17 Pro、iPhone 17 Pro Max 各做一次第 1～6 步：外框都貼著目標（四邊差不多 5pt 的間距），說明卡完整在螢幕內，文字沒有被截斷。SE 上第 2 步（兩張牌）說明卡在外框上方，要檢查沒有被狀態列或最上方的模式切換蓋住。

## 二、再看導覽

| # | 步驟 | 預期 |
|---|---|---|
| 1 | 導覽看完後，點 `?`，點 `再看導覽` | 規則面板關閉，導覽從第 1 步開始。 |
| 2 | 中途點 `跳過` | 導覽結束，遊戲照常。 |
| 3 | 選牌動畫進行中點 `?` | 沒有反應（與以前相同）。 |
| 4 | 導覽進行中，用 VoiceOver 掃頂端的模式切換 | 掃不到（導覽是 modal）；也點不到。 |

## 三、規則面板

| # | 步驟 | 預期 |
|---|---|---|
| 1 | 點 `?` | 規則面板。內容依序：規則摘要、這個模式的六關目標（今日挑戰 23、44、73、100、200、310；自由練習入門 18、34、56、80、145、240）、今日挑戰說明、危險度表（1 格 10%／2 格 25%／3 格 42%／4 格 60%，倍數牌 不出現／×1.5／×2／×3）、八條特殊規則、金幣怎麼算（含例子）、拚超標的獎勵、保命符、破關之後。 |
| 2 | 在 iPhone SE 往下捲 | 內容可捲；底部的五個按鈕（兩排小按鈕 + `回到遊戲`）一直在畫面上，不需要捲到最底。捲動區底部有淡出提示。 |
| 3 | 點 `關閉音效` | 文字變 `開啟音效`，聲音關閉（存檔 `muted`）。 |
| 4 | 今日挑戰點 `放棄（算一次）` | 面板內出現確認：`放棄這次挑戰？這次會算一次挑戰（即使一手都還沒選），接著開始第 N 次。`，按鈕 `再想想`／`放棄`，都完整在螢幕內。 |
| 5 | 點 `再想想` | 回到規則面板，次數不變。 |
| 6 | 再按一次 `放棄（算一次）` → `放棄` | 面板關閉，開始第 N 次，頂列 `第 N 次`；上方提示 `已放棄，開始第 N 次挑戰`。 |
| 7 | 自由練習點 `?` | 按鈕寫 `放棄重來`；確認文字 `放棄這局？會換一副新牌重新開始。`。 |
| 8 | 點 `回到遊戲` | 面板關閉。 |
| 9 | 點 `選擇難度` | 規則面板關閉，打開選擇難度面板（與點頂列標籤相同）。 |

## 四、就地說明（逐項對照）

| # | 位置 | 預期 |
|---|---|---|
| 1 | 進度條下方 | 白線左側 `過關 34`，右側 `超標 51 +$3`，兩個不重疊；超標後右側變金色。 |
| 2 | 過關按鈕未達標 | 主文 `達到 34 分才能過關`，小字 `過關 $3 ＋ 剩下每手 $1 ＋ 超標再 $3`。精簡關基本是 $6，豐收關每手 $2，傳說難度基本 $2。 |
| 3 | 過關按鈕可過關 | 主文 `過關，拿 $N`，小字 `基本 $3 + 剩 4 手 $4　·　到 51 再 +$3`（已超標不顯示後半）。 |
| 4 | 道具列 | 四格各有一行小字：`自動擋爆`、`看會不會爆`、`換一組牌`、`得分 ×2`。保命符虛線框，數量 0 時變淡。 |
| 5 | 點保命符 | 提示 `保命符 ×N：選到會爆的牌時自動擋下，不扣手數，連中也不會斷`；沒有時 `沒有保命符了，過關後可以在商店買`。 |
| 6 | 爆炸的牌面 | 紅底，`爆了`（重壓時 `爆了 −N`），小字 `扣 1 手`。（`-boomPair` 可以固定看到） |
| 7 | 保命符擋下／拆彈 | 淺藍底，`保命符擋下`／`拆彈成功`，小字 `不扣手數`。（`-boomPair -shield 1`、`-boomPair -blessings defuse`） |

## 五、VoiceOver（導覽覆蓋層）

開啟 VoiceOver（實機：設定 → 輔助使用；模擬器請用 Accessibility Inspector 或實機）。

| # | 步驟 | 預期 |
|---|---|---|
| 1 | 以 `-onboarding` 開啟 | VoiceOver 焦點自動落在說明卡文字：`新手導覽 1 / 6，目標分數，每關要在…`。 |
| 2 | 向右滑 | 依序：被標示的區塊（`標示的區塊：分數區`）→ 說明卡文字 → `跳過` → `下一步`。**不會**跑到後面的遊戲畫面（牌、道具、過關按鈕）、頂列或模式切換（模式切換也被隱藏）。 |
| 3 | 雙擊 `下一步` | 焦點回到新一步的說明卡文字；被標示的區塊改成 `標示的區塊：兩張牌`。 |
| 4 | 兩指畫 Z（escape） | 等同 `跳過`，導覽結束。 |
| 5 | 最後一步 | 沒有 `跳過`；`開始玩` 結束導覽，焦點回到遊戲。 |
| 6 | 導覽結束後 | 遊戲元件可以正常用 VoiceOver 操作。 |

## 六、減少動態效果（Reduce Motion）

設定 → 輔助使用 → 動態效果 → 減少動態效果，開啟後：

| # | 步驟 | 預期 |
|---|---|---|
| 1 | `-onboarding` 開啟 | 遮罩淡入（很短），沒有滑動。 |
| 2 | 按 `下一步` | 外框**直接跳到**下一個目標，沒有 0.32 秒的滑動。 |
| 3 | 規則面板 | 淡入淡出，沒有從下方滑入。 |

## 七、存檔相容

| # | 步驟 | 預期 |
|---|---|---|
| 1 | 用 Phase 4 以前的 `save-v6.json`（沒有 `onboardingDone`，或值為 false）開啟 | 視為還沒看過，第一次開啟會出現導覽；看完後寫入 `onboardingDone: true`，其他欄位原封不動。 |
| 2 | 存檔裡 `onboardingDone` 已經是 true | 不出現導覽。 |

## 八、測試環境

UI 測試與單元測試請用專用模擬器（`xcodebuild ... -destination 'id=<專用模擬器>' -parallel-testing-enabled NO`），不要和其他 App 共用同一台模擬器。單元測試的 host App 不會讀寫真正的 `save-v6.json`（Debug 專用：`XCTestConfigurationFilePath` 存在時存檔放記憶體，也不啟動廣告、不出現導覽）。
