## 給實作者（包含 AI 模型）的規則

- **不要自行改動規則常數。** 目標分數、機率、價格都是用模擬調過的。要調整時先改 `core.js`、重跑模擬和測試向量，再改 Swift。
- **所有隨機都必須走可指定種子的亂數**（`01-game-rules.md` 的「亂數」一節）。今日挑戰要求所有人拿到同一副牌，用 `Int.random`、`Double.random` 或 `shuffled()` 都會破壞這點。
- **規則程式和畫面分開。** 規則寫成不依賴 SwiftUI 的純函式或 struct，才能單元測試。
- **文案以繁體中文（zh-Hant）為準**，其他五個語系（en、ja、ru、zh-Hans、zh-HK）在第 7 階段補齊。
- **既有的服務直接沿用**：`AudioManager`、`HapticManager`、`RewardedAdManager`、`BannerAdView`、`AppOpenAdManager`。
- 每個階段完成後對照 `04-implementation-plan.md` 的驗收標準。實作者不要自己驗收自己的成果，交給另一個審查者。

## 遊戲一句話

每關在有限手數內二選一翻牌，把分數打到目標。每張牌的危險度（爆炸機率）直接畫在牌上，危險越高分數越大。爆炸只扣一手，不會直接結束。六關一局，中間有商店可以買祝福組出自己的打法，破關後還有無盡關卡和六個難度。今日挑戰每天一副牌、所有人相同、可以無限重打，紀錄是「第幾次破關」。

## 和現有 App 的差異

| 項目 | 現有 App（`GameLogic.swift`） | 新設計 |
|---|---|---|
| 選牌 | 兩張牌必有一張炸彈，各 50%，選數字大的就對了 | 每張牌獨立判定，危險度 1～4 格寫在牌上，兩張危險度一定不同 |
| 爆炸 | 一局結束 | 扣一手；保命符可以擋下，不扣手數 |
| 結構 | 一直選到爆炸為止 | 六關，每關 7 手內達到目標分數 |
| 運算 | 加 60%、減 20%、乘 20% | 加分牌與倍數牌，沒有減法 |
| 收手 | 文案說「見好就收」，但沒有收手功能 | 達標後可隨時過關，剩下的手數換金幣 |
| 成長 | 無 | 金幣、商店、10 種祝福、4 種道具 |
| 變化 | 無 | 每兩關一個魔王，其他關卡各一條特殊規則 |
| 每日 | 每天 5 次、記當日最佳 | 今日挑戰：日期種子、可無限重打、記第幾次破關 |
| 破關後 | 無 | 無盡關卡、六個難度 |
| 說明 | 獨立的機率頁（數字和程式不符） | 新手導覽，規則寫在操作的位置 |
| 紀錄 | 每日最佳分數列表（未排序） | 「我的紀錄」頁：個人紀錄、里程碑、今日挑戰日曆、難度與祝福統計 |

## 設計決策紀錄

這些決定都經過討論和模擬。之後如果有人想改，請先讀這裡的理由。

1. **保留二選一，但每張牌獨立判定並顯示危險度。** 原本兩張牌一定有一張是炸彈，牌面數字只影響賺多少，所以永遠選大的就好，玩家其實是在擲硬幣。現在安全與高報酬要自己取捨，四種危險度的期望值刻意調得接近，沒有永遠最好的選法。
2. **爆炸只扣一手。** 原本一半的局在第一下就結束，平均只玩 1 關。
3. **每關分數歸零，不採用累加制。** 曾經試過讓分數帶到下一關，但倍數牌乘在累積的總分上，爆炸又不扣分，×2 變成幾乎沒有風險，模擬中只選安全牌的全破率只剩 0.1%。每關歸零後，倍數的報酬有上限，風險才有意義。
4. **連中會跨關延續。** 這樣「不屈」「連勝體質」這類連中祝福才有價值。原本每關歸零，一關只有 7 手，連勝體質要連中 8 次才有效果，永遠拿不到。
5. **「不屈」是爆炸時連中減半，無條件進位。** 連中跨關後，「只少 1」太強；一般的減半在連中 1 時會變成 0，等於沒效果。無條件進位兩者都避開。
6. **魔王每兩關一個（第 2、4、6 關），其他關卡各抽一條特殊規則。** 讓每一關都有不同的判斷重點。
7. **「濃霧」整張牌蓋住。** 原本只藏危險度，但加分範圍幾乎不重疊、倍數又一對一對應危險度，看數字就猜得出來，等於沒效果。
8. **「超標」是目標的 1.5 倍，獎勵 $3。** 原本叫「雙倍目標」，和道具「雙倍」撞名。
9. **今日挑戰可以無限重打，記第幾次破關，目標是入門的 1.3 倍。** 同一位置一定發同樣的牌，重打時記得翻過的結果就能走更遠，像每天的謎題。放棄也算一次挑戰，避免刷次數。
10. **破關後有無盡關卡與六個難度。** 難度規則會累加，破關一個才解鎖下一個。今日挑戰不受難度影響。
11. **說明寫在操作的位置，加上六步新手導覽。** 金幣公式寫在過關按鈕上，超標獎勵寫在進度條上，保命符底下寫「自動擋爆」。
12. **「我的紀錄」頁。** 每個數字都有里程碑可以挑戰，打破紀錄時即時提示。
