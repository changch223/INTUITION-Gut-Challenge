## Description (876/4000)

1ステージにつき手数は7手。1手ごとに、2枚のカードから1枚を選びます。

カードには「危険度」が直接描かれています。導火線のマスは1〜4個。多いほど爆発しやすく、得点も大きくなります。安全に稼ぐか、高倍率に賭けるか。どのカードも小さな駆け引きで、いつでも正解といえる選び方はありません。

【爆発しても減るのは1手だけ】
爆弾を引いてもゲームオーバーにはならず、1手減るだけ。目標スコアに届けばステージクリアで、残り手数はコインに変わります。ボーナスラインまで届けばコインがさらに増えます。セーフを続けると「連続成功」ボーナスが貯まり、次のステージにも持ち越せますが、爆発すると0に戻ります。

【6ステージ、自分だけの戦い方】
・ステージの合間のショップで、10種類の祝福と4種類のアイテムをコインで購入
・お守りは爆発を自動で防ぎ、透視・リロール・ダブルは好きなタイミングで使えます
・ステージ2・4・6はボス戦（濃霧、重圧、不安定…）。ほかのステージにもそれぞれ特別ルール
・祝福は最大5個。組み合わせしだいで戦い方が変わります

【デイリーチャレンジ】
毎日1デッキ、全員が同じカードとルールで挑戦します。最初はかなり難しいですが、何度でも再挑戦できます。同じ位置には同じカードが出るので、結果を覚えるほど先へ進めます。記録は「何回目で全クリアしたか」。戦績マスは友だちにシェアできます。

【全クリアのあとも楽しめる】
・エンドレス：終わりはなく、2ステージごとにボス。どこまで行ける？
・6段階の難易度：全クリアすると次が解放され、ルールは重なっていきます
・フリープレイ：いつでも新しいプレイを始めて、新しい作戦を試せます

【マイ記録】
最高スコア、最長連続成功、最多クリアステージ、デイリーチャレンジのカレンダー、難易度別・祝福別のクリア率など。すべての数字に次のマイルストーンがあり、記録を更新するとその場でお知らせします。

ルールはかんたん、片手でOK、1プレイは数分。あなたの直感は、どれくらい当たる？

広告が含まれます。
