# 02 畫面與互動

原型 `reference/prototype.html` 右側的手機就是這份規格的實際樣子，有疑問時以原型行為為準。原型裡的 CSS class 名稱寫在括號裡，方便對照。

## 1. 視覺方向

遊戲畫面是單一的鈷藍夜色外觀，不跟隨系統深淺色。這也順便解決了現有 App 在深色模式下可能白字白底的問題。所有顏色寫死在設計 token 裡。

| Token | 值 | 用途 |
|---|---|---|
| `bgTop` → `bgMid` → `bgBottom` | `#2638DC` → `#131C96` → `#0B1060`，165° 線性漸層 | 遊戲背景 |
| `ink` | `#FFFCF2` | 主要文字、淺色牌面 |
| `inkMuted` | `#C6CCFF` | 次要文字 |
| `inkFaint` | `#9AA3F0` | 提示文字 |
| `night` | `#10133A` | 倍數牌面、底部面板文字 |
| `gold` | `#FFB21E` | 金幣、過關按鈕、連中、超標、新紀錄 |
| `mint` | `#16D6A3` | 安全、進度條、破關 |
| `red` | `#FF3B5C` | 爆炸、魔王、失敗 |
| `danger1`～`danger4` | `#0FA57C`、`#D99A00`、`#F06A1D`、`#F0284B` | 引信格與危險度文字 |
| `fog` | `#8088B8` | 被蓋住的牌 |
| `sheetBg` | `#FFFCF2` | 底部面板背景 |
| `sheetText` / `sheetMuted` | `#10133A` / `#5A6088` | 面板文字 |

字體：數字與大標題用 Bricolage Grotesque（800 粗），內文用 Noto Sans TC。若不想打包字體，數字可用 SF Pro Rounded Heavy，內文用系統字體，但數字一定要用等寬數字（`.monospacedDigit()`）。

**畫面固定直向。** 目前專案的 iPhone 允許橫向，要在 target 設定中關閉。

## 2. 主畫面（由上到下）

```
┌────────────────────────────────────┐
│ [第 2 關 / 6] [$7] [11/16 第 2 次 ▾]  ★  ? │  頂列
│ ┌魔王 濃霧 其中一張牌完全蓋住…──────┐ │  規則橫條（每關都有）
│               37                   │  分數（大）
│      目標 34　已達標，超標線是 51     │  目標說明
│ ████████████████▌───────────┃      │  進度條（白線在 66.7%）
│          過關 34 ┃     超標 51 +$3   │  進度條標籤
│ 剩 4 手 ●●●●○○○        連中 3 · 得分 ×1.75 │
│ [不屈] [加碼]                        │  已有的祝福
│ ┌──────────┐  ┌──────────┐        │
│ │  加分     │  │  倍數     │        │  兩張牌（佔滿剩餘高度）
│ │  +6      │  │  ×2      │        │
│ │ 成功 → 47 │  │ 成功 → 74 │        │
│ │ ▮□□□     │  │ ▮▮▮□     │        │
│ │危險 1·10% │  │危險 3·42% │        │
│ └──────────┘  └──────────┘        │
│ [1 保命符] [1 透視] [1 重抽] [0 雙倍]  │  道具列
│ [   過關，拿 $10                    ] │  過關按鈕
│ [ 基本 $3 + 剩 4 手 $4 · 到 51 再 +$3 ] │
└────────────────────────────────────┘
```

### 2.1 頂列（`.top`）

- **關卡標籤**：`第 N 關 / 6`；無盡模式時為 `無盡 第 N 關`。
- **金幣**：金色膠囊，`$N`。
- **日期／難度標籤**（可點）：今日挑戰顯示 `M/D 第 N 次 ▾`，自由練習顯示 `練習 · 入門 ▾`。點了打開「選擇難度」面板。
- **★**：打開「我的紀錄」。
- **?**：打開規則面板。
- 遊戲動畫進行中（`locked`），或已有面板打開時，這些按鈕不反應。

### 2.2 規則橫條（`.boss`）

- 魔王關：紅底白字，`魔王 濃霧` 加粗，後面接效果說明。
- 一般關卡：半透明白底，`本關規則 加溫` 的名稱用金色，後面接效果說明。
- 每關都會顯示。

### 2.3 分數區（`.score`）

- **分數**：大字、等寬數字。數字變多時縮小：3 位以下 84pt、5 位以下 64pt、7 位以下 50pt、9 位以下 40pt。改變時用 420ms ease-out 的數字滾動。
- **目標說明**，依狀態顯示：
  - 未達標：`目標 34　還差 12`
  - 已達標：`目標 34　已達標，超標線是 51`
  - 已超標：`目標 34　超標達成，過關多拿 $3`
- **進度條**：0 到超標線。過關線是一條白色直線，位置在 66.7%（因為目標 ÷ 超標線 = 1/1.5）。填色在未超標時是 mint，超標後是 gold。寬度變化用 450ms 動畫。
- **進度條標籤**：過關標籤靠在白線左側（`過關 34`），超標標籤靠右（`超標 51 +$3`），超標後變金色。兩個標籤不可重疊。

### 2.4 手數與連中（`.meta`）

- 左邊：`剩 N 手`，加上 N 個實心圓點和用掉的空心圓點，總數是這關的 `sp`。
- 右邊：連中膠囊。連中 0 時是暗色的 `連中 0`；連中 ≥ 1 時是金色的 `連中 3 · 得分 ×1.75`。

### 2.5 祝福列（`.bls`）

已有的祝福顯示成小標籤，可重複的加上 `×2`。一個都沒有時顯示 `還沒有祝福，過關後可以在商店買`。

### 2.6 牌（`.cd`）

兩張牌並排，佔滿剩下的高度，圓角 22。

| 部位 | 加分牌 | 倍數牌 | 被濃霧蓋住 |
|---|---|---|---|
| 底色 | `ink`，文字 `night` | `night`，數字 `gold` | 灰色斜紋 |
| 小標 | `加分` | `倍數` | `蓋住的牌` |
| 大字（60pt） | `+6` | `×2` | `?` |
| 預覽 | `成功 → 47` | `成功 → 74` | `翻開才知道` |
| 引信 | 4 格，前 d 格亮起，顏色是 `danger{d}` | 同左 | 4 格全暗 |
| 危險度文字 | `危險 1 · 10%` | `危險 3 · 42%` | `危險 ？` |

- 「成功 →」的值已經算進連中與雙倍，玩家不用心算。
- 透視啟用時，牌頂端加一個標籤：`安全`（綠）或 `會爆`（紅）。
- VoiceOver：`加 6，危險 1 格` / `乘 2，危險 3 格` / `蓋住的牌，分數和危險度不明`。

### 2.7 道具列（`.items`）

四格等寬。每格是：數量（粗體）、名稱、一行小字說明。

| 道具 | 小字 | 點擊 |
|---|---|---|
| 保命符 | `自動擋爆` | 不是主動道具；點了顯示說明提示。數量 0 時變淡 |
| 透視 | `看會不會爆` | 啟用，數量顯示 ✓，格子變金色 |
| 重抽 | `換一組牌` | 立刻換牌，新牌做發牌動畫 |
| 雙倍 | `得分 ×2` | 啟用，數量顯示 ✓，格子變金色 |

數量 0 且未啟用時停用。

### 2.8 過關按鈕（`.bank`）

兩行字：主文 + 小字。

| 狀態 | 主文 | 小字 | 樣式 |
|---|---|---|---|
| 未達標 | `達到 34 分才能過關` | `過關 $3 ＋ 剩下每手 $1 ＋ 超標再 $3`（依規則精簡、豐收、傳說調整數字） | 停用，暗色 |
| 已達標、可過關 | `過關，拿 $10` | `基本 $3 + 剩 4 手 $4　·　到 51 再 +$3`（已超標時不顯示後半） | gold，外圈呼吸光 1.1s |

## 3. 選一手的流程與時間

1. 點牌（或鍵盤左右鍵）。立刻鎖定輸入。
2. 選中的牌放大到 1.04，另一張變淡（35% 不透明）並縮到 0.96。引信快速閃爍。
3. 播放 `d + 1` 聲短促的滴答聲，間隔 115ms。
4. 滴答結束後 140ms 揭曉：

| 結果 | 牌面 | 音效 | 觸覺 | 其他 |
|---|---|---|---|---|
| 安全 | mint 底，大字 `+12` | 依連中數升高音高的成功音 | `playSuccess` | 粒子噴發，數量隨得分增加；分數滾動 |
| 爆炸 | red 底，大字 `爆了`（重壓時 `爆了 −40`），小字 `扣 1 手` | 爆炸聲 | `playError` | 畫面搖晃 0.4s；提示（見第 6 節） |
| 保命符擋下 | 淺藍底，`保命符擋下`，小字 `不扣手數` | 清脆兩聲 | `playClick` | 提示剩幾張 |
| 拆彈 | 同上，`拆彈成功`，小字 `不扣手數` | 同上 | 同上 | |

5. 800ms 後：手數用完就自動過關或進入失敗；否則發新牌（從下方 26pt 滑入、彈性 0.26s），解除鎖定。
6. 跨過目標的那一手：提示 `達標！可以過關，也可以拚超標 51`，並播放達標音。

減少動態效果（Reduce Motion）開啟時：不搖晃、不噴粒子、不做數字滾動，揭曉延遲 40ms、換牌延遲 260ms。

## 4. 過關與商店

過關時播放過關音、彩帶、觸覺 `[20, 40, 20]`，750ms 後打開商店面板。

### 4.1 商店面板

```
第 1 關過關，拿到 $10
商店　$12
┌ 過關基本 $3 ─ 剩下的手數（每手 $1） $4 ─ 打到超標線 $3 ─ 這關合計 $10 ┐
┌ 下一關目標 34　魔王「濃霧」：其中一張牌完全蓋住… ┐   （魔王關用淡紅底）
祝福（已有 1 / 5）
[ 不屈　爆炸時連中減半…                 $5 ]
[ 加碼（已有 1）　加分牌的分數 +25%…     $4 ]
[ 已購買　這個位置賣完了 ]
道具
[透視 $3 有 1] [重抽 $2 有 1] [雙倍 $3 有 0] [保命符 $4 有 1]
[換一批 $1]               [前往第 2 關]
```

- 金幣不夠或祝福已滿時停用該按鈕。
- 買東西後面板內容就地更新，捲動位置不變。
- 前往下一關時提示這關的魔王或規則：`魔王「濃霧」：…` 或 `第 3 關規則「加溫」：…`，顯示 2.8 秒。

## 5. 一局結束

### 5.1 手數用完、沒達標

```
第 4 關 · 手數用完
還差 12 分
看一支獎勵廣告可以多拿 2 手，每局限一次。
[結束這局]  [看廣告，多 2 手]
```

已經看過廣告時直接進入結算。

### 5.2 結算面板

- 小標：`止步第 4 關`／`六關全破`／`無盡模式止步第 9 關`，加上 `今日挑戰第 2 次` 或 `難度「入門」`。
- 大標：稱號 = `直覺迷路了 / 感覺不太靈 / 普通水準 / 小有靈感 / 預感強到爆 / 神準直覺 / 歐皇現世`（依過關數 0～6，超過 6 用最後一個）。前六關都超標時加上 `· 全關超標`。
- 總分（大字）。
- 戰績格：每關一格，綠色 `過`、金色 `超`、紅色 `敗`，未到的關卡是灰色。無盡關卡往右延伸。
- 說明：`綠色是過關，金色是超標。前六關超標 2 / 6，無盡關卡多打了 3 關。`
- 剛解鎖難度時：`解鎖新難度「進階」：目標分數 ×1.15。難度會累加，前面的規則也一起生效。`
- 這局打破個人紀錄時：`這局打破 2 項個人紀錄：最長連中 9、單關最高分 120`。
- 這局帶的祝福。
- 可複製的戰績文字，例如：

```
INTUITION++ 11/16 今日挑戰
第 3 次挑戰破關 · 總分 682
🟩🟨🟩🟩🟨🟩
```

按鈕組合：

| 情況 | 第一排 | 第二排（主要按鈕） |
|---|---|---|
| 破關（任何模式） | `複製戰績`、**`繼續無盡關卡`** | 今日挑戰：`同一副牌再打`、`去自由練習`；自由練習：`挑戰難度「下一級」`（已解鎖時）或 `再來一局`，加上 `同一副牌再打` |
| 今日挑戰沒破關 | `複製戰績`、`去自由練習` | **`再挑戰一次（第 N 次）`** |
| 自由練習沒破關 | `複製戰績`、`換難度`、`再來一局` | **`同一副牌再打`** |

自由練習的 `再來一局` 是同難度換一副新牌；`同一副牌再打` 是同種子、同難度重來。使用者決定「同一副牌再練」為主要選項，所以自由練習沒破關時以它為主要按鈕（與原型不同，以本表為準）。

今日挑戰沒破關時，按鈕上方加一段說明：`同一副牌在同樣的位置會發同樣的牌，哪張會爆也一樣。記住這次翻到的結果，下次就能避開。今日挑戰可以無限重打，紀錄會寫你第幾次破關。`

## 6. 提示（toast）文案

畫面上方的黑色膠囊，預設 1.8 秒。

| 時機 | 文案 |
|---|---|
| 達標 | `達標！可以過關，也可以拚超標 {S}` |
| 爆炸 | `爆了：扣 1 手{、分數減半}{，連中 N 歸零}` |
| 不屈發動 | `不屈發動：連中 {s0} → {s1}，得分仍 ×{m}（沒有不屈會歸零）` |
| 保命符擋下 | `保命符擋下爆炸：這手不算、不扣手數，連中保留（剩 N 張）` |
| 拆彈 | `拆彈：這關第一次爆炸無效，不扣手數` |
| 點保命符 | `保命符 ×N：選到會爆的牌時自動擋下，不扣手數，連中也不會斷`；沒有時：`沒有保命符了，過關後可以在商店買` |
| 透視 | `透視：這一手的結果已經顯示在牌上` |
| 重抽 | `重抽：換了一組新牌` |
| 雙倍 | `雙倍：下一張牌的得分加倍` |
| 看完廣告 | `多了 2 手` |
| 換難度 | `自由練習 · 難度「進階」` |
| 進入下一關且有千里眼 | 在魔王／規則提示下加第二行 `千里眼：送你 1 個透視` |

**新紀錄提示**是另一個元素：分數區下方的金色膠囊 `★ 新紀錄　最長連中 9`，2.4 秒，同一項紀錄一局只出現一次，第一局（沒有舊紀錄）不出現。

## 7. 新手導覽（第一次打開時）

半透明深色遮罩，挖空要介紹的區塊並加金色外框，旁邊是說明卡片（區塊在畫面下半時卡片在上方，反之在下方）。卡片有 `新手導覽 N / 6`、標題、說明、`跳過`、`下一步`（最後一步是 `開始玩`）。

| 步驟 | 圈出 | 標題 | 說明 |
|---|---|---|---|
| 1 | 分數區 | 目標分數 | 每關要在 7 手內把分數打到目標，下一關從 0 開始。進度條上的白線是過關線，最右邊是超標線。上方的橫條是這關的特殊規則，每關都不一樣。 |
| 2 | 兩張牌 | 二選一，看危險度 | 底下的引信格數越多越容易爆，分數也越大。深色牌是倍數牌，乘在這關的分數上，分數越高越值錢。爆了只會扣 1 手，不會直接結束。 |
| 3 | 手數與連中 | 手數與連中 | 白點是剩下的手數。連續選中會累積連中，每次得分多 25%，最多兩倍。連中會帶到下一關，但爆一次就歸零。 |
| 4 | 道具列 | 保命符與道具 | 保命符不用按。選到會爆的牌時它自動擋下：這手不算、不扣手數，連中也不會斷。透視、重抽、雙倍要自己按，用一次就沒了。 |
| 5 | 過關按鈕 | 過關拿金幣 | 達標後按這裡過關。金幣＝基本 $3＋剩下每一手 $1，打到超標線（目標的 1.5 倍）再多 $3。金幣在關卡之間的商店買祝福和道具。 |
| 6 | 分數區 | 要不要拚超標？ | 達標後可以繼續打。到超標線多拿 $3、戰績格變金色，分數也算進最後的總分。代價是每多用一手少 $1，也多一次爆炸的風險。破關後還有無盡關卡和更高的難度。 |

完成或跳過後不再自動出現，規則面板裡有 `再看導覽`。

## 8. 規則面板（? 按鈕）

依序：

1. 一段規則摘要：每關在手數內把分數打到目標就能過關，下一關從 0 開始，各關分數加起來是總分。每張牌獨立判定，爆了只扣一手。連中一次得分多 25%，最高 2 倍，會帶到下一關，爆一次歸零。
2. 這個模式的六關目標，以及「第 2、4、6 關是魔王關，其他關各抽一條特殊規則」。
3. **今日挑戰**說明：每天換一副牌、所有人相同、目標比入門高 30%、可無限重打、同位置同樣的牌、紀錄寫第幾次破關。
4. 危險度表：危險度、爆炸機率、倍數牌倍率。
5. 八條特殊規則的列表。
6. **金幣怎麼算**表：過關基本 $3、剩下的每一手 +$1、打到超標線 +$3、利息每持有 $5 +$1（最多 $3）。附例子：`第 1 關目標 18、超標線 27。用 4 手打到 28 分就過關，剩 3 手：$3 + $3 + $3 = $9。`
7. **拚超標的獎勵**：多 $3、戰績格變金色、前六關都超標有「全關超標」稱號；代價是每多用一手少 $1，也多一次爆炸的風險。
8. **保命符**：不用按，自動擋下，這手不算、不扣手數、連中不斷；開局送 1 張，商店 $4。
9. **破關之後**：無盡關卡沒有終點、每 2 關一個魔王；破關解鎖下一個難度，共六級。
10. 按鈕：`我的紀錄`、`開啟／關閉音效`、`再看導覽`、`選擇難度`、`放棄（算一次）`（今日挑戰）或 `放棄重來`（自由練習）、`回到遊戲`。

## 9. 選擇難度面板

- 說明：破關一個難度就解鎖下一個；難度會累加；今日挑戰有自己的難度（目標 ×1.3），可以無限重打。
- 六個選項：`1　入門`＋規則說明＋右側的模擬全破率。未解鎖的停用，說明改成 `破關「入門」後解鎖`。目前的難度標 `（目前）`。
- 選了就在自由練習開新局。若自由練習有進行中的局，說明裡提示 `目前這局會放棄`，並把那局記為放棄。

## 10. 我的紀錄（★）

底部面板，上方四個分頁。資料定義見 `03-data-persistence.md`。

### 10.1 總覽

- 四格數字（2×2）：單局最高總分、最長連中、最多過關數（超過 6 時副標寫 `無盡多打 N 關`）、已解鎖難度。每格有一行副標，例如 `11/13 創下`。
- **個人紀錄與下一個目標**：六項紀錄，每項一列：名稱、數值、進度條、`下一個目標 500　3 / 5`（全部達成時寫 `全部達成`）。這局剛打破的紀錄用金色並標 `這局剛破`。
- **累計**：總局數（含放棄 N 局）、破關率、選中率（安全手數 / 總手數）、保命符擋下次數、全關超標次數。

### 10.2 今日挑戰

- 四格數字：破關天數（`4 / 10`，副標 `玩過的天數`）、連續破關（`3 天`，副標 `最長 5 天`）、最少幾次破關、平均幾次破關。
- **今天每一次打到哪裡**：柱狀圖，每次挑戰一根，高度 = 過了幾關（滿格 6），柱頂標 `3 關` 或 `破關`，破關那根是綠色，其他是鈷藍。最多顯示最近 8 次，下方標 `第 N 次`。下方一句總結。
- **最近 14 天**：7 欄日曆。破關的日子是 mint 底，寫第幾次破關；挑戰過但沒破的日子是紅框，寫 `×3`；沒玩的日子空白；今天加深色外框。

### 10.3 難度

表格：難度、局數、破關、最高總分。第一列是今日挑戰，未解鎖的難度寫 `未解鎖`。

### 10.4 祝福

表格：祝福、帶過幾局、破關、破關率，依局數排序。下方提醒：`局數少的時候破關率會跳很大，打越多越準。`

### 10.5 空狀態

還沒有任何紀錄時，不顯示分頁，只顯示：`打完第一局後，這裡會出現你的最高分、最長連中、今日挑戰第幾次破關等紀錄。每一項都有下一個目標可以挑戰。`，以及 `先看範例`、`開始玩`。範例資料上方要有明顯的 `範例資料，不是你的紀錄` 標籤，並有 `看我的紀錄` 按鈕可以切回。

## 11. 模式切換

畫面最上方（遊戲區外）放兩個分段按鈕：`今日挑戰`、`自由練習`。兩個模式各自保留進行中的局，切換時直接接著玩，不算放棄。遊戲動畫進行中不能切換。

## 12. 廣告位置

| 類型 | 位置 | 規則 |
|---|---|---|
| 獎勵廣告 | 手數用完的面板 | 多 2 手，每局一次。廣告載入失敗時按鈕停用並寫 `廣告暫時無法載入` |
| 插頁廣告 | 結算面板出現前 | 建議每 3 局最多一次，今日挑戰第一次挑戰不放。現有的開啟 App 廣告建議移到這裡 |
| 橫幅廣告 | 只放在商店與結算面板底部 | 不放在主畫面，避免誤觸牌和過關按鈕 |

原型裡的廣告是 2.5 秒的模擬畫面，正式版接 `RewardedAdManager.shared.showAd(from:reward:)`。
