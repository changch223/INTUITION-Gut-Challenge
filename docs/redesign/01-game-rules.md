# 01 遊戲規則

所有規則的程式版本在 `reference/core.js`。本文件是它的文字說明，數值與 `core.js` 第 1～6 行的常數一致。Swift 版必須通過 `reference/test-vectors.json` 的所有項目。

## 1. 一局的結構

- 一局 6 關（`STAGES = 6`）。破關後可選擇進入無盡關卡，沒有終點。
- 每關一開始分數是 0，手數是 `stagePicks`（標準是 7）。
- 每一手從兩張牌選一張。選中的牌會判定是否爆炸：
  - **安全**：分數增加，連中 +1，手數 -1。
  - **爆炸**：手數 -1，連中歸零（有「不屈」時減半），分數不變（魔王「重壓」例外）。
  - **被擋下**（「拆彈」或保命符）：什麼都不扣，連中保留。
- 分數 ≥ 目標，而且這關至少選過 1 手時，可以隨時按「過關」。
- 手數用完時：分數 ≥ 目標就自動過關；否則失敗。失敗時每局可以看一次獎勵廣告，手數設成 2 繼續這關。
- 過關後拿金幣，進入商店，再前往下一關。
- 最後的總分 = 各關結算時的分數加總（失敗那關也算進去）。

## 2. 常數

| 常數 | 值 | 意義 |
|---|---|---|
| `P` | `[0.10, 0.25, 0.42, 0.60]` | 危險度 1～4 格的基本爆炸機率 |
| `ADD` | `[3, 5, 7, 10]` | 危險度 1～4 格加分牌的基準分數 |
| `MUL` | `[0, 1.5, 2, 3]` | 危險度 1～4 格倍數牌的倍率（1 格沒有倍數牌） |
| `PICKS` | `7` | 每關基本手數 |
| `STAGES` | `6` | 一局的關數 |
| `STR` | `1.5` | 超標線 = 目標 × 1.5 |
| `TGT` | `[18, 34, 56, 80, 145, 240]` | 第 1～6 關的原始目標（顯示前會經過 `nice()`） |
| `EG` | `1.25` | 無盡關卡每關目標的成長倍率 |
| `DAILY_TM` | `1.3` | 今日挑戰的目標倍率 |

## 3. 目標分數

```
nice(x):
  if x < 100: return round(x)
  p = 10 ^ (floor(log10(x)) - 1)
  return round(x / p) * p          // 保留兩位有效數字

targetAt(stage, lv):
  t = stage <= 6 ? TGT[stage-1] : TGT[5] * EG^(stage-6)
  return nice(t * (lv >= 1 ? 1.15 : 1))

targetOf(run, stage) = nice(targetAt(stage, run.lv) * (run.tm ?? 1))   // 今日挑戰 tm = 1.3
stretch(run) = nice(target(run) * 1.5)
```

- `round` 一律是 JavaScript 的 `Math.round`，對正數等於 `floor(x + 0.5)`。Swift 的 `.rounded()` 對正數結果相同。
- 實際顯示的目標（入門）：18、34、56、80、**150**、240，無盡 300、380、470、590⋯⋯（145 經過 `nice` 變成 150）。
- 今日挑戰 2026/11/16 的目標：23、44、73、100、200、310。完整表在 `test-vectors.json` 的 `targets`。

## 4. 手數

```
maxPicks = max(1, 7 + (祝福「多一手」層數) - (lv >= 2 ? 1 : 0))
stagePicks = max(1, maxPicks - (魔王急迫 ? 2 : 0) - (規則精簡 ? 1 : 0))
```

- 每關開始時 `picks = sp = stagePicks`。`sp` 用來判斷「這關是否已選過至少 1 手」（`picks < sp`）。
- 看廣告續命：`picks = 2`（不是 +2），每局限一次（`adUsed`）。

## 5. 亂數（今日挑戰的確定性靠這一節）

### 5.1 演算法

原型使用 mulberry32 產生器和一個 FNV 風格的雜湊。Swift 版必須逐位元相同：

```swift
struct Mulberry32 {
    private var a: UInt32
    init(_ seed: UInt32) { a = seed }
    mutating func next() -> Double {          // 回傳 [0, 1)
        a = a &+ 0x6D2B79F5
        var t = (a ^ (a >> 15)) &* (1 | a)
        t = (t &+ ((t ^ (t >> 7)) &* (61 | t))) ^ t
        return Double(t ^ (t >> 14)) / 4294967296.0
    }
}

func seedOf(_ xs: Int...) -> UInt32 {
    var h: UInt32 = 2166136261
    for x in xs {
        h ^= UInt32(truncatingIfNeeded: x)
        h = h &* 16777619
        h ^= h >> 13
    }
    return h
}
```

### 5.2 種子的來源

| 用途 | 種子 |
|---|---|
| 一局的種子 `seed` | 今日挑戰：日期整數 `YYYYMMDD`（例如 `20261116`，使用者本地時區）。自由練習：`0..<2^31` 的隨機整數，存在存檔裡 |
| 一手的兩張牌 | `seedOf(seed, stage, idx, rr)` |
| 商店的祝福貨架 | `seedOf(seed, 77, stage, srr)` |
| 每關的特殊規則 | `seedOf(seed, stage, 99) % 8` |

- `idx`：這關已經選了幾手（含被擋下的），每手 +1，換關歸零。
- `rr`：這一手用了幾次「重抽」，每手歸零。
- `srr`：這次商店換了幾批貨，換關歸零。
- 因為發牌只看 `(seed, stage, idx, rr)`，**同一個位置一定發同樣的兩張牌，和前面選了什麼無關**。這是今日挑戰重打時可以靠記憶的基礎。注意：倍數牌只在這關分數 ≥ 4 時出現，祝福也會改變爆炸機率，所以「同樣的牌」是指同樣的亂數，最後結果可能因狀態不同而變。

## 6. 發牌 `genPair`

亂數的取用順序必須完全一致：

```
r = Mulberry32(seedOf(seed, stage, idx, rr))
md  = 這關的特殊規則
top = (md == calm) ? 3 : 4
d1 = 1 + floor(r() * top)
d2 = 1 + floor(r() * (top - 1)); if d2 >= d1 { d2 += 1 }      // 兩張危險度一定不同
sc = (1 + 0.3 * (stage - 1)) * (1 + 0.25 * 加碼層數)
dp = (lv >= 4 ? 0.05 : 0) + (魔王不穩 ? 0.10 : 0) + (md == fuse ? 0.08 : 0)

mk(d):                                   // 每張牌依序取 3 個亂數
  u = r(); tm = r(); b = r()
  p = round((P[d-1] + dp) * 100) / 100
  if d == 1 且有祝福「穩手」: p = 0
  if tm < (md == wild ? 0.56 : 0.28) 且 d > 1 且 這關分數 >= 4:
      op = ×; n = MUL[d-1] + 0.5 * 滾雪球層數
      if d == 4 且有「賭徒」: n *= 1.5
  else:
      op = +
      n = max(1, round(ADD[d-1] * sc * (0.75 + 0.6*u) * (md==fuse ? 1.4 : 1) * (md==small && d==1 ? 2 : 1)))
      if d == 4 且有「賭徒」: n = round(n * 1.5)
  boom = b < p

a = mk(d1); b = mk(d2)
f = r() < 0.5 ? 0 : 1
if 這關魔王是濃霧: [a, b][f].fog = true
return [a, b]
```

## 7. 得分 `deltaOf`

```
smult = min(1 + (md == heat ? 0.5 : 0.25) * streak, 有「連勝體質」 ? 3 : 2)
base  = op == + ? n : 這關分數 * (n - 1)
delta = round(base * smult * (雙倍道具啟用中 ? 2 : 1))
```

牌面上「成功 → X」顯示的是 `這關分數 + delta`。

## 8. 選牌結算 `pickCard`

依下列順序判斷，只會發生一種：

1. 牌會爆，且有「拆彈」，且這關還沒用過：無效化。`defused = true`。不扣手數，連中保留。
2. 牌會爆，且保命符 > 0：保命符 -1。不扣手數，連中保留。
3. 牌會爆：`s0 = streak`；`streak = 有不屈 ? ceil(s0 / 2) : 0`；魔王重壓時 `lost = floor(這關分數 / 2)`，分數 -= lost；手數 -1。
4. 安全：分數 += delta；連中 +1；手數 -1；特殊規則「淘金」時金幣 +1。

之後一律：雙倍道具關閉、透視關閉、`idx += 1`、`rr = 0`。

## 9. 過關與金幣

```
rewardParts:
  基本   = (lv >= 5 ? 2 : 3) + (md == lean ? 3 : 0)
  剩手數 = picks * (md == rich ? 2 : 1)
  超標   = 這關分數 >= stretch ? 3 : 0
  利息   = 有「利息」 ? min(3, floor(目前金幣 / 5)) : 0        // 用拿獎勵之前的金幣計算
reward = 以上加總
```

- 過關紀錄（戰績格）：超標記 2（金色），一般過關記 1（綠色），失敗記 0（紅色）。
- 第 6 關過關且不在無盡模式時，這局結果是「破關」。之後玩家可以選擇繼續無盡關卡（`endless = true`，進商店後前往第 7 關）。

## 10. 換關 `nextStage`

`stage += 1`；分數 = 0；`picks = sp = stagePicks`；`idx = rr = srr = 0`；拆彈重置；雙倍與透視關閉；有「千里眼」時透視 +1；發新牌。**連中不歸零。**

## 11. 商店

- **祝福貨架**：從 10 個祝福中篩出可買的（未擁有的，在擁有數 < 5 時才可買；已擁有的只有可重複的才列入），用 `seedOf(seed, 77, stage, srr)` 的亂數做 Fisher–Yates 洗牌（`for i = n-1 down to 1: j = floor(r() * (i+1)); swap`），取前 3 個。買走的位置顯示「已購買」。
- **換一批**：$1，`srr += 1` 後重新產生。
- **祝福上限 5 個**（不同種類），可重複的祝福疊加層數不佔新的格子。
- **價格**：難度「傳說」（lv 5）所有價格 +$1。

### 11.1 道具

| 道具 | 價格 | 效果 |
|---|---|---|
| 透視 `peek` | $3 | 這一手兩張牌直接標示「安全」或「會爆」 |
| 重抽 `roll` | $2 | `rr += 1` 換一組新牌，透視失效 |
| 雙倍 `dbl` | $3 | 下一張選中的牌得分 ×2 |
| 保命符 `shield` | $4 | 被動，自動擋下一次爆炸 |

開局：透視 1、重抽 1、雙倍 0、保命符 1（難度「專家」以上全部為 0）。

### 11.2 祝福

| id | 名稱 | 效果 | 價格 | 可重複 |
|---|---|---|---|---|
| `add` | 加碼 | 加分牌的分數 +25% | $4 | 是 |
| `snow` | 滾雪球 | 倍數牌的倍率 +0.5 | $6 | 是 |
| `cool` | 穩手 | 危險 1 格的牌絕對不會爆 | $5 | 否 |
| `gamb` | 賭徒 | 危險 4 格的牌獎勵 ×1.5 | $5 | 否 |
| `hot` | 連勝體質 | 連中加成上限從 2 倍提高到 3 倍 | $6 | 否 |
| `grit` | 不屈 | 爆炸時連中減半（無條件進位），不會歸零 | $5 | 否 |
| `hand` | 多一手 | 每關多 1 手 | $6 | 是 |
| `eye` | 千里眼 | 每關開始時送 1 個透視 | $5 | 否 |
| `bank` | 利息 | 過關時每持有 $5 多拿 $1，最多 $3 | $4 | 否 |
| `defuse` | 拆彈 | 每關第一次爆炸無效 | $7 | 否 |

祝福的列舉順序（影響商店洗牌結果）：`add, snow, cool, gamb, hot, grit, hand, eye, bank, defuse`。

## 12. 魔王與特殊規則

```
bossOf(stage):
  if stage 是奇數: 無魔王
  if stage <= 6: [fog, shaky, crush][stage/2 - 1]          // 第 2、4、6 關
  else: [short, fog, shaky, crush][(stage/2 - 4) % 4]       // 第 8、10、12⋯⋯ 關
```

| 魔王 | 名稱 | 效果 |
|---|---|---|
| `fog` | 濃霧 | 隨機一張牌整張蓋住，看不到分數、類型、危險度 |
| `shaky` | 不穩 | 每張牌爆炸率 +10% |
| `crush` | 重壓 | 爆炸時，這關目前的分數砍半（前面各關不受影響；保命符和拆彈擋下時不砍） |
| `short` | 急迫 | 這關少 2 手（只在無盡關卡出現） |

非魔王關卡的特殊規則：`MODK[seedOf(seed, stage, 99) % 8]`，順序固定為：

| id | 名稱 | 效果 |
|---|---|---|
| `heat` | 加溫 | 每連中一次得分 +50%（上限不變） |
| `calm` | 平靜 | 不會出現危險 4 格的牌 |
| `wild` | 狂野 | 倍數牌出現率加倍（28% → 56%） |
| `lean` | 精簡 | 少 1 手，但過關基本獎勵 +$3 |
| `rich` | 豐收 | 剩下的每一手換 $2 |
| `small` | 穩賺 | 危險 1 格的牌分數 ×2 |
| `fuse` | 短引信 | 每張牌爆炸率 +8%，加分牌分數 ×1.4 |
| `gold` | 淘金 | 每選中一張牌 +$1 |

## 13. 難度（自由練習）

規則會累加：選 lv 3 時，lv 1、lv 2 的規則也生效。

| lv | 名稱 | 新增規則 | 模擬全破率 |
|---|---|---|---|
| 0 | 入門 | 標準規則 | 約 16% |
| 1 | 進階 | 目標分數 ×1.15 | 9.9% |
| 2 | 老手 | 每關少 1 手 | 4.6% |
| 3 | 專家 | 開局沒有保命符和道具 | 2.8% |
| 4 | 大師 | 每張牌爆炸率 +5% | 1.2% |
| 5 | 傳說 | 商店貴 $1，過關基本獎勵只剩 $2 | 0.8% |

- 破關（前 6 關全過）某個難度，解鎖下一個（`unlock = max(unlock, lv + 1)`，上限 5）。今日挑戰破關視同 lv 0 破關。
- 今日挑戰固定使用 lv 0 的規則，再把目標 ×1.3。

## 14. 今日挑戰

- 種子是當天日期（本地時區），每天換一副牌，所有人相同。
- 可以無限重打。每次結束（失敗、破關、放棄）都算一次挑戰。
- 紀錄：挑戰次數、是否破關、第幾次破關、最高總分、每次過了幾關。細節見 `03-data-persistence.md`。
- 重打時同一位置發同樣的牌（見 5.2），所以記住結果可以越打越遠。

## 15. 平衡數據

都是模擬結果，不是真人數據。模擬的玩家用「期望值」選牌（`(1 - p) × delta`，濃霧牌用平均值估），過關條件一達成就過關，商店照價格由低到高能買就買，不用道具。

## 16. 測試向量

`reference/test-vectors.json` 內容：

| 鍵 | 用來驗證 |
|---|---|
| `mulberry32` | 種子 1 和 20261116 的前 5 個亂數 |
| `seedOf` | 4 組雜湊結果 |
| `nice` | 取整的邊界情況 |
| `targets` | 六個難度第 1～10 關的目標、今日挑戰 20261116 的目標 |
| `stageRule_seed20261116` | 第 1～12 關的魔王或特殊規則 |
| `genPair_*` | 指定狀態下第 0～4 手的兩張牌（危險度、機率、類型、數值、是否爆炸、是否被蓋住） |
| `shopOffer_*` | 指定種子與換貨次數下的祝福貨架 |
| `stagePicks_lv2_stage8_short` | 難度老手、無盡第 8 關（急迫）的手數 |

浮點數比對請容許 `1e-12` 的誤差，其他值必須完全相等。
